# Primera-part Com crear un GitHub pas a pas 1. Entrar a la pàgina Ves a: [[GitHub](https://github.com/) ](https://github.com/) 2. Crear un compte Clica “Sign up” per registrate Escriu: el teu email una contrasenya un nom d’usuari (serà el teu nom públic a GitHub) Després segueix els passos que et demanen (confirmar email, etc.). 3. Entrar al teu compte Quan ja tens el compte creat: Inicia sessió amb el teu email i contrasenya 4. Crear el teu primer projecte (repositori) A dalt a la dreta, fes clic al “+” Clica “New repository” 6. Posar-li nom: Escriu un nom (ex: primer-projecte) Pots posar una descripció si vols 7. Triar opcions Public (tothom el pot veure) Private (només tu el veus) 8. Crear-lo i ja tindriem el repositori Clica “Create repository” 9.Ara crearem la web anant a: Add file i Create new file 10. Posem el que creiem, Commit changes, i ja tindriem la pagina 11. Activar la web Anem a Settings Busca Pages Seleccionem: Branch: main i Guardem (Hem de crear ua pagina html perquè veiem la web i posar el mateix nom en el meu cas adriaafl.github.io 12. Obrir la web Entra a: 👉 https://el-teu-usuari.github.io I ja està! Ja tens el teu GitHub creat.

He triat Python, perquè és senzill i està suportat a VSCode. Per poder programar i executar correctament he instal·lat: Extensió de Python Python Debugger Pylance I he instalat Python en el google Aquestes eines permeten escriure codi, detectar errors i executar programes basicament sense aixo no pots ferlo servir . Després posem el codi, jo en aquest cas he fet el del DNI, al canto es poden veure les extensions: dni = int(input("Introdueix el número del DNI (sense lletra): ")) lletres = "TRWAGMYFPDXBNJZSQVHLCKE" lletra = lletres[dni % 23] print("La lletra del DNI és:", lletra) Despres cliquem a Run hi ja funionara dni = int(input("Introdueix el número del DNI (sense lletra): ")) Primer demano a l’usuari que escrigui el número del DNI. Amb input() es llegeix el que escriu per teclat, però això entra com a text, així que amb int() ho converteixo a número per poder fer càlculs. En C# seria semblant, però una mica més llarg: int dni = int.Parse(Console.ReadLine()); lletres = "TRWAGMYFPDXBNJZSQVHLCKE" Aquí guardo totes les lletres possibles del DNI dins d’una cadena de text. L’ordre és important perquè després segons el número sortirà una lletra o una altra. En C# seria pràcticament igual: string lletres = "TRWAGMYFPDXBNJZSQVHLCKE"; lletra = lletres[dni % 23] En aquesta línia faig el càlcul de la lletra. El % 23 serveix per obtenir el residu de dividir el número entre 23, i aquest resultat indica quina posició de la cadena hem d’agafar. Basicament, el número dóna una posició i d’allà surt la lletra correcta. En C# funciona gairebé igual: char lletra = lletres[dni % 23]; print("La lletra del DNI és:", lletra) Per acabar, mostro per pantalla la lletra calculada. En C# seria:Console.WriteLine("La lletra del DNI és: " + lletra);
